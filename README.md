# Shopping Trend Analysis

## Overview

Shopping Trend Analysis is a data analysis project that explores customer purchasing behavior using a shopping trends dataset. The project focuses on identifying patterns related to demographics, seasonal trends, discounts, product preferences, and customer spending habits. The insights generated can help businesses improve marketing strategies, customer engagement, and decision-making.

## Features

* Customer behavior analysis
* Age and gender-based shopping trends
* Seasonal purchase analysis
* Product category insights
* Discount and promo code impact analysis
* Payment and shipping preference visualization
* Data visualization using Python libraries
* Statistical analysis for trend identification

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains customer shopping information including:

* Age
* Gender
* Product Categories
* Purchase Amount
* Subscription Status
* Discounts and Promo Codes
* Payment Methods
* Shipping Types
* Review Ratings
* Seasonal Purchase Trends

## Project Objectives

* Analyze customer shopping behavior
* Identify purchasing trends and patterns
* Understand the influence of discounts and demographics
* Generate business insights for better marketing strategies

## Installation

Clone the repository:

```bash
git clone https://github.com/12sahu/shopping-trend-analysis.git
```

Move into the project directory:

```bash
cd shopping-trend-analysis
```

Install required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook file and execute the cells to view the analysis and visualizations.
